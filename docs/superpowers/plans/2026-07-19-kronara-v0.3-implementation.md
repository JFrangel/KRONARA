# Kronara v0.3 Analytical Intelligence Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a governed analytical researcher, RAG v2, performance scientist and continuous improvement loop while preserving Rust authority and Reddit rights restrictions.

**Architecture:** Rust owns configuration, secrets and external effects. Python implements versioned cognitive contracts, context compilation, retrieval, evidence, deterministic analytics and learning decisions. SQLite remains transactional truth; vector, lexical and graph indexes remain rebuildable.

**Tech Stack:** Tauri 2, Rust, Svelte/Vite, Python 3.11+, LangGraph 1.x, SQLite/FTS5, sqlite-vec, httpx, pytest, FFmpeg and faster-whisper in later media tasks.

## Global Constraints

- Python never reads production secrets or executes arbitrary shell.
- Reddit user content is never training data without express, recorded permission.
- Every external source is untrusted data with provenance and freshness.
- Every number is produced by a deterministic function with `AnalysisTrace@1`.
- Every promotion is versioned, evaluated, reversible and scoped.
- Tests are written and observed failing before production code.
