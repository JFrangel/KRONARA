# Perfiles de género por programa (KRONARA presenta)

> Cada programa vive bajo la marca KRONARA con identidad propia. El motor narrativo usa
> el perfil del programa para ajustar registro, estructura y rúbrica. Patrones abstractos,
> nunca copia de una fuente.

Las reglas base de cada programa viven en `python/kronara/program_narrative.py`.
Desde Programas > Configuración se pueden guardar overrides manuales por programa;
el override se usa en concepto, blueprint, escenas, revisión y crítica sin editar
el código. Las plantillas son contratos de forma, no guiones para copiar.

## Decisiones Difíciles — dilemas y conflictos personales
- Núcleo: un personaje enfrenta una elección sin salida limpia; ambas opciones cuestan.
- Registro: íntimo, reflexivo, cotidiano creíble.
- Motor: el dilema se agrava con información parcial hasta forzar una decisión irreversible.
- Cierre: consecuencia proporcional + pregunta moral abierta al público.

## Confesiones Anónimas — secretos y experiencias
- Núcleo: una voz en primera persona revela un secreto por capas.
- Registro: confesional, cercano, con detalle sensorial que da veracidad.
- Motor: cada revelación parcial reencuadra la anterior; el verdadero secreto llega tarde.
- Cierre: el peso de haberlo dicho; el residuo emocional.

## Crónicas de Justicia — traiciones, pruebas y consecuencias
- Núcleo: injusticia comprensible + protagonista subestimado + evidencia que cambia el poder.
- Registro: crónica tensa, precisa, con datos verificables cuando el género lo exige.
- Motor: escalada de abuso → punto de no retorno → preparación con pistas → revelación → giro de poder.
- Cierre: consecuencia proporcional (no ruina imposible ni cárcel automática).

## Mentes Ocultas — psicología, manipulación y misterio
- Núcleo: un manipulador con lógica interna; la protagonista descubre el patrón.
- Registro: inquietante, de sospecha creciente, atención a lo no dicho.
- Motor: pistas de comportamiento sembradas; la verdad se arma con detalles.
- Cierre: el límite que la protagonista impone; el costo de ver claro.

## Viernes Paranormal — terror y fenómenos sobrenaturales
- Estructura de 10 fases: incidente inquietante → cotidiano creíble → primera anomalía →
  explicación racional → anomalía que la rompe → investigación/advertencia →
  presencia/descubrimiento → clímax → consecuencia → residuo inquietante.
- Reglas: ambigüedad controlada, exposición tardía, detalle sensorial, no depender de sustos de volumen.
- Cierre: puede dejar una pregunta abierta.

## Historias de Medianoche — relatos largos y cinematográficos
- Núcleo: arco amplio, varias escenas, tiempo para atmósfera e interioridad.
- Registro: cinematográfico, de imágenes fuertes y silencios.
- Motor: apto para multi-parte; cada parte cierra con gancho salvo la última.
- Cierre: eco que permanece.

## El Caso de la Semana — episodio premium o especial
- Núcleo: pieza mayor que combina investigación, personajes y revelación de alto impacto.
- Registro: producción cuidada, ritmo de largometraje corto.
- Motor: admite formato largo (horizontal) + variantes cortas verticales.
